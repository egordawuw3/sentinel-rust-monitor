# 🛰 Sentinel (Rust Edition)

Высокопроизводительный асинхронный сервис для мониторинга веб-сайтов.
Написан на Rust с использованием экосистемы Tokio.

## ⚡️ Функционал
- **Мониторинг 24/7:** Проверка доступности сайтов каждую минуту.
- **Умные Алерты:** Уведомления в Telegram с защитой от "мигания" (Retry logic).
- **База данных:** SQLite для надежного хранения целей мониторинга.
- **Асинхронность:** Способен мониторить сотни сайтов одновременно без блокировок.

## 🛠 Технический стек
- **Core:** Rust, Tokio
- **Bot:** Teloxide
- **Http:** Reqwest
- **DB:** SQLx + SQLite
